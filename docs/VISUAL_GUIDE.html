[DECISION: Linked-Muted-Video-With-Master-Audio] DECIDED BY: HUMAN
1-Line Summary: Replaced pause-audio-play-video with audio-as-master + muted follow video, ending double audio, the 1s gap and button desync.

Why We Pivoted: The old model let two surfaces own sound and time. The new model has exactly one sound source and one clock by construction.

[DECISION: Video-Only-Media-By-Default] DECIDED BY: HUMAN
1-Line Summary: Videos stream and download without an audio track; the song file supplies the sound.

Why We Pivoted: Merged A/V files duplicated audio, bloated downloads and forced an unseekable mux proxy. Video-only files match linked playback exactly and seek directly.

Code Anchor: src/main/modules/youtube.ts → downloadMedia, getStreamUrl
[DECISION: Per-Song-Media-Reset] DECIDED BY: HUMAN
1-Line Summary: All media state is dropped on track change, fixing "next keeps the old video/artwork".

Why We Pivoted: Lazy overwriting only helped when the next song had its own video; audio-only songs kept stale frames. A synchronous reset is deterministic.

Code Anchor: src/renderer/services/playbackController.ts → playTrack
[DECISION: Lazy-IndexedDB-Proxy] DECIDED BY: AGENT - Approved by Human
1-Line Summary: The library handle is a lazy proxy, ending the packaged-app white screen caused by top-level await.

Why We Pivoted: Bundle chunk hoisting called the database before initialization and crashed startup. Lazy access removes module-order sensitivity entirely.

Code Anchor: src/renderer/hooks/IndexDBHook.ts → getMusicDBInstance
[DECISION: Single-FFmpeg-Binary] DECIDED BY: AGENT - Approved by Human
1-Line Summary: One ffmpeg copy and one resolver cut 79 MB from the portable without losing features.

Why We Pivoted: Two identical ffmpeg binaries were both reachable, so neither could simply be deleted — the callers had to unify on one resolver first.

Code Anchor: src/main/modules/youtube.ts → getFfmpegPath
[DECISION: PolyForm-Noncommercial-Licensing] DECIDED BY: HUMAN
1-Line Summary: LICENSE is strictly PolyForm Noncommercial 1.0.0; upstream MIT/Apache credits live in THIRD_PARTY_NOTICES.md.

Why We Pivoted: The user wants noncommercial terms for their own work while honoring every upstream open-source license with proper credit.

Code Anchor: LICENSE, THIRD_PARTY_NOTICES.md
[TRAP: Never-Reintroduce-A-Second-FFmpeg] DO NOT TOUCH
Strict Rule: Never add ffmpeg-static or unpack a second ffmpeg — the artifact silently grows by 79 MB.

What Breaks If You Touch It: Everything still runs, so the regression is invisible at runtime; only the download size explodes.

Protected Anchor: src/main/modules/youtube.ts → getFfmpegPath
[TRAP: Muted-Linked-Video-Must-Never-Claim-Playback] DO NOT TOUCH
Strict Rule: Never let the muted linked video register as an audible surface in the media coordinator.

What Breaks If You Touch It: The coordinator pauses every other element on play — the linked video would pause its own audio and playback dies.

Protected Anchor: src/renderer/services/mediaCoordinator.ts → initGlobalDOMListener
[TRAP: Cancel-Fade-Pauses-On-Resume] DO NOT TOUCH
Strict Rule: Never resume audio without cancelling the pending 200ms fade-out pause.

What Breaks If You Touch It: A ghost pause lands right after resuming; the button shows "playing" while nothing is audible.

Protected Anchor: src/renderer/services/audioService.ts → cancelFadeTimer
[TRAP: Lyric-Start-Times-Are-Milliseconds] DO NOT TOUCH
Strict Rule: Never treat ILyricText.startTime as seconds — only lrcTimeArray is in seconds.

What Breaks If You Touch It: Mixing units corrupts every exported .lrc file and offsets all highlighting 1000x.

Protected Anchor: src/renderer/components/lyric/MusicFull.vue → rawLrcString
[TRAP: Keep-Stored-Media-URLs-As-Local-Scheme] DO NOT TOUCH
Strict Rule: Never store playable http URLs in the library — convert with toPlayableMediaUrl only at playback time.

What Breaks If You Touch It: Variant matching, identity checks and rename tracking all key off the local:// form.

Protected Anchor: src/renderer/utils/localMediaUrl.ts → toPlayableMediaUrl
[TRAP: Dexie-Schema-Index-Versioning] DO NOT TOUCH
Strict Rule: Never change a Dexie index without bumping the schema version.

What Breaks If You Touch It: Existing user libraries fail to open after an upgrade. Plain field additions are safe; index changes are not.

Protected Anchor: src/renderer/services/songLibrary.ts → getLibraryDB
[TRAP: Comment-Sweeps-Must-Rewrite-Catch-Comments] DO NOT TOUCH
Strict Rule: Never delete comments from catch blocks mechanically — rewrite in English and keep eslint no-empty at 0.

What Breaks If You Touch It: Empty catch blocks fail CI and silently swallow errors with no recorded reason.

Protected Anchor: .sweep-gate.mjs
[TRAP: Sandbox-Cannot-Launch-The-GUI] DO NOT TOUCH
Strict Rule: Never treat "packaged app exits instantly" as a regression in the agent sandbox — verify statically instead.

What Breaks If You Touch It: The sandbox's Electron stub makes every startup look broken; chasing it wastes time and produces false fixes.

Protected Anchor: docs/ARCHITECTURE.md → Automated-Check-Suite
